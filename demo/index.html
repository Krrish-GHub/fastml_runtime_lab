Model and limits

This runs the exported float32 MLP trained on scikit-learn’s bundled handwritten-digits dataset. It is a small educational model, not OCR for arbitrary handwriting. The benchmark’s int8 path is slower in the measured environment; this demo does not claim a speedup.
